MongoDB $jsonSchema Validation Live Demo

Demonstrating strict schema validation enforced natively by MongoDB at the database engine level.

Test 1: Insert Valid Document

Inserts a document satisfying all required fields (item_id, item_name, category, location, date_reported, status) and matching allowed enums.

{
  "item_id": "TEST-VAL-001",
  "item_name": "Valid Test Book",
  "category": "Books",
  "type": "lost",
  "description": "Database Systems Concepts 7th Ed",
  "location": "Central Library",
  "status": "open",
  "reported_by": "USR-101"
}
Test 2: Invalid Category (Enum Violation)

Attempts to insert a document with an illegal category value not present in the allowed enum list.

{
  "item_id": "TEST-VAL-002",
  "item_name": "Invalid Category Item",
  "category": "ILLEGAL_CATEGORY_VALUE", //  REJECTED!
  "type": "lost",
  "description": "Validation test document",
  "location": "Science Block 1",
  "status": "open",
  "reported_by": "USR-101"
}
Test 3: Missing Required Field

Attempts to insert a document without the mandatory location field.

{
  "item_id": "TEST-VAL-003",
  "item_name": "Missing Location Item",
  "category": "Electronics",
  "type": "found",
  "description": "Validation test without location",
  // "location": OMITTED! ->  REJECTED!
  "status": "open",
  "reported_by": "USR-105"
}
Test 4: Illegal Status Value

Attempts to insert a document with status 'in_review' (allowed: open, matched, resolved, closed).

{
  "item_id": "TEST-VAL-004",
  "item_name": "Illegal Status Test",
  "category": "Stationery",
  "type": "lost",
  "description": "Validation test document",
  "location": "Main Auditorium",
  "status": "in_review", //  REJECTED!
  "reported_by": "USR-102"
}
